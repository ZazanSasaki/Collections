# ZAZAN COLLECTIONS v2
Dark black/red personal Anime, Manga and TV Series archive.

Features: manual poster upload (8 MB per image), add/edit/delete, categories, statuses, genre tags, year, personal rating, progress, notes, search, filters, sorting, dashboard counters, JSON backup export/import, IndexedDB local storage and offline-capable PWA.

## Android install using GitHub Pages
1. Create a GitHub repository named `zazan-collections`.
2. Extract this ZIP and upload the contents (not the containing folder) to the repository root.
3. Open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait for deployment and open the HTTPS Pages URL in Chrome on Android.
5. Chrome menu (⋮) → Install app / Add to Home screen.

This is an installable PWA, not a signed APK. Entries and poster images stay in this browser's local IndexedDB on this device. There is no cloud sync. Browser storage limits apply; export backups regularly and do not clear site data without a backup.
